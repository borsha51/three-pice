# Made by Nexora — Three-Piece Edit

Premium frontend-only three-piece fashion storefront.

## Deploy on Render
Build command: `npm run build` · Publish directory: `dist`.

No Turso/database/backend is required. Cart and wishlist use browser storage. A future backend can be connected through `VITE_API_BASE_URL`; never expose Turso credentials in the frontend.

Hidden demo admin route: `#/nexora-admin`. Add real authentication before production admin use.
